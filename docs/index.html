01 / BACKGROUND

本地视频静音循环，图片也能用。完整显示或铺满裁切，位置、亮度与播放速度都可调整。

02 / APPEARANCE

两种外观，各有分寸。

Dark 和 Light 各自保存参数。逐项复制，或一次同步全部；不合适，随时撤销。

03 / CONTROL

看见背景，也看清内容。

侧栏、输入框、代码块与信息面板分别调节透明度。文字、面板与强调色也由你决定。

04 / LOCAL

你的素材，留在本机。

无需素材账号，不上传背景文件。调整即时生效，参数按背景保存在本机；原生设置页保持原样。

下载前，了解这些。

兼容性与首次打开

要求 macOS 13+，包含 Apple Silicon 与 Intel 架构；当前实机验证为 Apple Silicon。v0.3.0 仅有 ad-hoc 签名，尚未经过 Apple 公证，首次打开可能被系统拦截。确认下载来源后，按 macOS“隐私与安全性”的提示处理，无需关闭系统安全保护。

视频格式与黑边

推荐 H.264 MP4，素材最大 64 MiB。也支持图片 PNG、JPEG、WebP。完整显示会在比例不匹配时留边；铺满裁切能填满窗口，但会裁掉部分画面。

重启之后会自动生效吗？

参数保存在本机，但普通重启 Codex 后需要再次打开 Codex Skin 应用皮肤。应用成功后可以关闭 Codex Skin，背景会继续播放。

与 Codex 是什么关系？

这是独立的社区项目，与 OpenAI 无隶属关系，不是官方插件。通过本机调试连接加载皮肤，不修改 Codex 安装文件。Codex 更新可能需要重新适配。
